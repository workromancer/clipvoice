# ClipVoice `0.1.1-beta` Test & Verification Evidence

All tests below were executed on macOS 26.2 (`arm64`) with Xcode 26.5 / Swift 6.3.2 using isolated temporary stores (`/tmp/clipvoice-e2e.*/history.json`) and synthetic test strings only. No personal clipboard content, credentials, or user home directories are committed or shipped. Because E2E tests exercise live `pbcopy` capture on macOS, `scripts/e2e_test.sh` temporarily snapshots the active system pasteboard into a `0600` temp archive (`scripts/pb_snapshot.swift save`) and restores exact UTI types and raw data bytes on exit (`scripts/pb_snapshot.swift restore`), leaving `~/Library/Application Support/ClipVoice` untouched.

## 2. End-to-End Verification (`./scripts/e2e_test.sh`)

   - Verified `filter-url`/`filter-all`, `pause-button` gating, and `delete-button-clip-2` via `AXPress`.
3. **`clipvoice-cli` Exact `--raw` Bytes & Non-Destructive `install-skill`**:

5. **Korean Localization (`--locale ko`), Hidden HUD Respect & Pasteboard Restore**:
