# ClipVoice Test & Verification Evidence

All tests below were executed on macOS 26.2 (`arm64`) with Xcode 26.5 / Swift 6.3.2 using isolated temporary stores (`/tmp/clipvoice-e2e.*/history.json`), isolated `UserDefaults` suites (`--prefs-suite`), and synthetic test strings only. No personal clipboard content, credentials, or user home directories are committed or shipped. Because E2E tests exercise live `pbcopy` and `NSPasteboard` capture/write on macOS, `scripts/e2e_test.sh` temporarily snapshots the active system pasteboard into a `0600` temp archive (`scripts/pb_snapshot.swift save`) and restores exact UTI types and raw data bytes on exit (`scripts/pb_snapshot.swift restore`), leaving `~/Library/Application Support/ClipVoice` and normal user preferences untouched.
