# ClipVoice `0.1.0-beta` Test & Verification Evidence

All tests below were executed on macOS 26.2 (`arm64`) with Xcode 26.5 / Swift 6.3.2 using isolated temporary stores (`/tmp/clipvoice-e2e.*/history.json`) and synthetic test strings only. No personal clipboard history, credentials, or user home directories were accessed, shipped, or committed. The user's system pasteboard is snapshotted before E2E tests (`scripts/pb_snapshot.swift save`) and restored with exact UTI types and raw data bytes on exit.
