# ClipVoice App Logo Asset

`clipvoice-icon.png` was generated by Codex using built-in `imagegen` with the following prompt summary:

> Deep graphite midnight canvas, luminous cyan clipboard with V-shaped audio waveform, subtle violet glass/titanium edge, no text.

During packaging (`scripts/build.sh` and `scripts/build_iconset.swift`), this asset is converted into `AppIcon.icns` and embedded as `AppLogo.png` inside `ClipVoice.app/Contents/Resources/`.
