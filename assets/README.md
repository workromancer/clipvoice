# ClipVoice App Logo Assets

- `clipvoice-icon-v2.png` (current): Minimal pale silver clipboard/voice abstract mark on matte indigo, generated by Codex using built-in `imagegen` for the Linear-inspired native macOS UI.
- `clipvoice-icon.png` (legacy `0.1.1-beta`): Deep graphite midnight canvas, luminous cyan clipboard with V-shaped audio waveform, subtle violet glass/titanium edge, no text.

During local app assembly (`scripts/build.sh` and `scripts/build_iconset.swift`), `clipvoice-icon-v2.png` is converted into `AppIcon.icns` and embedded as `AppLogo.png` inside `ClipVoice.app/Contents/Resources/`.
